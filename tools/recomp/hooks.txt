# Game functions replaced by host code (docs/RECOMPILER.md "Hooks").
#
#   <symbol> [us] [pal] [jp] [kr]  the function's body moves to <fn>_orig; HLE(<symbol>) replaces it
#                              and may call callOriginal(c, "<symbol>")
#   <symbol> all               <symbol> is the USA name; the hook applies to every version: the
#                              recompiler finds the matched function (config/<id>/us_map.txt) and
#                              gives it the USA name there, so one HLE(<USA name>) serves all four
#   <module>::<symbol>         a function of a REL module (name from config/<id>/rels/<module>.txt);
#                              with "all": the USA fn_<id>_<offset>, matched via rels_us_map.txt
#   patch <id> <addr> <word>   runtime-switchable instruction patch (setPatch(id, on)); with "all"
#                              <addr> is the USA address, mapped into a hash-matched function
#
# Every named DOL function is replaceable by name already (no line needed; names like the SDK's
# are the same in every version); lines here are for auto-named and REL functions and patches.
# Prefer "all" (docs/SETUP.md "Version-aware code"). A line without "all" applies to the USA build
# unless it is tagged only "pal", "jp" and/or "kr"; to the European / Japanese / Korean build only
# when tagged "pal" / "jp" / "kr", and then <symbol> is that version's own name. A build fails
# when an entry matches nothing.
